# Security

If you find a security problem in LibreServ, **do not open a public issue or pull request.**

Email both:

- `trafficcone@onetrue.name`
- `max@plainskill.net`

## What to send

Enough that we can reproduce it: what you did, what happened, and what you think someone could do with it. Include the version or build if you know it. Do not need a long write-up.

## What we do

We read it, fix it, and tell you when it is safe to talk about in public.
