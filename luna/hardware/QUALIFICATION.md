# Luna hardware qualification — Ethernet (BOM lock)

Batch 1 ships with a patch cable. There is no USB Wi-Fi dongle.
The phone stays on home internet.

## Requirements
- Wired Ethernet to a LAN port on the home router or modem.
- HDMI (or the screen on the box) shows the current address and, while
  unclaimed, the device code (purchased from LibreLoom).
- No monitor and skipping Luna Connect means the box cannot be found
  until a screen is attached or Connect is used later.

## BOM
- Ethernet patch cable in the box (required).
- No USB Wi-Fi dongle.
- Official setup code for Lunas purchased from LibreLoom (factory: each flash peels from `TOKENS` on the installer USB’s `LUNAASSETS` partition).
