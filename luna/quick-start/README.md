# Luna quick-start print layout

This small React/Vite app renders two complete Luna quick-start guides on one
US Letter sheet.

## Run it

```bash
npm install
npm run dev
```

Open the local URL, enter one device token for each guide, and choose **Print
two guides**.

## Print and fold

Use these print settings:

- US Letter
- Landscape
- Two-sided
- Flip on the short edge
- 100% scale
- No margins
- Print backgrounds

Cut once along the center line to make two 11 × 4.25 inch strips. For each
strip, fold Panel C left over Panel B, then fold Panel A right over both.

The resulting reveal order is:

1. Welcome cover
2. Index on the left and Luna Connect on the right
3. Index, setup without Luna Connect, and troubleshooting
