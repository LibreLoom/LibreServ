Search resource costs

Illustrative estimates · one active worker · not measured on Wyse
Model and memory assumptions
Static text256-dimensional retrieval model, float32 table: about 30 MiB of weights, plus tokenizer and small buffers. Text extraction is separate.
OCRTesseract fast, one language and one bounded page. 125 MiB is an illustrative midpoint of the earlier 50–200 MiB estimate, not a measured average or limit.
Image embeddingMobileCLIP2-S0, float32, both encoders resident: about 285 MiB of raw weights, plus runtime, image buffers and activations. 400 MiB is illustrative; peak usage can be higher.
QuantizationIdeal 8-bit raw weights: about 7.5 MiB for the text model; 71 MiB for both image-search encoders. Runtime memory does not shrink by the same factor.
