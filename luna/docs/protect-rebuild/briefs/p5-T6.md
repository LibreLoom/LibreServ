## Behaviour
1. Filters: `All` / `Needs a look` / `Cloud` / `Drives` (add `{ value: "cloud", label: "Cloud" }` before Drives). Cloud = `kind === "cloud"`.
2. Rows (both kinds, from the `backups` prop): name, destination pill (`row.destination`), status pill, last good copy, as today. Private rows of the viewer show like other rows, plus a small `Pill` `Private` after the name.
3. **Private items rows.** Query `["private-backups-summary"]` → `/api/v1/private-backups/summary` (`retry: false`), `privateGroups(...)`. Each owner's group (match `ownerId` to the group's creator id; groups are by `created_by`, so make `groupByCreator` results carry the creator id, or match by name only if T4 already exposes the id) ends with one row:
   - `Private items` + status pill: `All backed up` (success) or `1 needs a look` / `N need a look` (warning). No names, paths, sizes.
   - Line: `Only <name> can see these.` (for the viewer's own group: `Yours. Open a private folder's shield to see each one.`)
   - An owner with no group of their own gets a group named by `name` (or `Deleted user`).
   - Deleted owner (`deleted`): the row reads `Private items · deleted user`; for an Admin it has a `Button variant="accent"` `Remove` (surface named for the row's backdrop) that opens `ConfirmModal` (`variant="danger"`): title `Remove a deleted user's private backups?`, body `Removes every backup of their private items, on drives and in the cloud. Nobody can open these anymore, so nothing is lost that anyone can use.` — check this is true against plan §7 ("cloud copies are unreadable without the phrase"; drive copies of a deleted owner follow the ownerless rules) and, if drive copies could still be opened by an Admin who adopted the items, drop the second sentence. Confirm label `Remove backups`. On confirm `DELETE /api/v1/private-backups/owners/{ownerId}`; success toast `Removed N backups`; invalidate `["private-backups-summary"]`, `["backups"]`, `["cloud-backups"]`. Failure: toast `Could not remove the backups` with description = the server sentence (the modal has closed).
   - The Private items row is filtered by chips: shown under All; under Needs a look only when `needsLook > 0`; hidden under Cloud and Drives.
4. **Source gone / stopped rows** (not clickable today): add a link line.
   - Drive kind: `<Link to={`/drives/${row.target_drive}?backups=1`}>Open the Backups folder on <InlinePill>{row.destination}</InlinePill></Link>` (T3 made the param work). Selection haptic on click.
   - Cloud kind: an external link `https://connect.luna.libreloom.org/backups` with text `Open Luna Connect`, `target="_blank" rel="noreferrer"`.
   - Link styling: underline in the accent colour (allowed: link underlines), text in the surface's own text colour.
5. Active rows still open the shield sheet. No downloads here.
6. Toasts only for the Remove action.
