## Rules (plan §2)
- A private item's backup is never on the Admins entry: `admins = false`.
- Drive kind: the owner plus anyone whose member grant with `CAP_VIEW` is **on the private item itself** (normalized grant path equals the item's path), any role, existing accounts only. A grant on an ancestor folder never reaches into a private item. Verify that rule with `grep -n "private" access.rs | head -30` before writing; if access.rs lets a grant inside the item count too, stop and report.
- Cloud kind: the owner only.
- A row whose owner's account is gone: `users` is just `[owner]` (it matches nobody; Admins act through the deleted-owner route in T11).

## Add
```rust
/// Where a folder sits relative to private items.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum PrivateSource {
    /// Not private and not inside a private item.
    Shared,
    /// The folder is itself a private item owned by `owner`.
    OwnItem { owner: String },
    /// The folder is inside a private item (or is private trash).
    Inside,
}

pub fn private_source(conn: &Connection, drive_id: &str, path: &str) -> PrivateSource;
pub fn for_private(conn: &Connection, drive_id: &str, path: &str, owner: &str) -> anyhow::Result<AccessList>;
pub fn for_row(conn: &Connection, row: &db::ProtectionRow) -> anyhow::Result<AccessList>; // replace T1's stub
/// Why a private row must stop now, or None. Used by drive and cloud repath checks.
pub fn private_stop_reason(conn: &Connection, row: &db::ProtectionRow) -> Option<&'static str>;
```
1. `private_source`: normalize with `crate::access::normalize_subject_path`. Mount point from `db::get_drive(conn, drive_id)` (empty mount → `Shared`, matching `auth::inside_private`). `crate::private::boundary_for(Path::new(&mount), &norm)`:
   - `Some(b)` and normalized `b.path == norm` → `OwnItem{owner: b.owner}`.
   - `Some(_)` otherwise → `Inside`.
   - `None` → `Inside` if `crate::files::is_trash_api(&norm)` and `trash_private_meta(...)` is `Some`, else `Shared`.
   Check `boundary_for` takes a drive-relative path without a leading slash (read `private.rs` ~284 and `canonical`).
2. `for_private`: owner always in `users`; add grant holders per the rule; sorted, no duplicates; `admins: false`.
3. `for_row`:
   - `row.private_owner` empty → `for_source(conn, &row.source_drive, &row.source_path)`.
   - `kind == "cloud"` → `AccessList{users: vec![owner], admins: false}`.
   - else → `for_private(conn, &row.source_drive, &row.source_path, &row.private_owner)`.
4. `private_stop_reason(row)` (only for rows with `private_owner` set):
   - `private_source` is `OwnItem{owner}` with `owner == row.private_owner` → `None`.
   - `OwnItem` with another owner → `Some("This folder now belongs to someone else.")`.
   - `Inside` → `Some("This private item is now inside another private item.")`.
   - `Shared` → `Some("This folder is no longer a private item.")`.
   - The drive not mounted (empty mount point) → `None` (no decision while it's away).
   These strings are user-facing; keep them exactly.
