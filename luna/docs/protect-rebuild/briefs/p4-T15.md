## Behaviour (plan §2, §7, §8)
Add a query: `["private-item", driveId, objectPath]` → `GET /api/v1/private-backups/item?drive=…&path=…` (encodeURIComponent both). While it loads, the sheet renders as today.

1. **Someone else's private item** (`private && !mine`):
   - Intro shows one line: `Only <InlinePill>{owner_name}</InlinePill> can back up this item.`
   - No "Back up to …" / "Turn on cloud backup" controls. Existing drive backups the person can see (from `/api/v1/backups`) still list with their status, without Run / Delete unless `can_delete`.
   - The cloud section shows nothing for them (cloud copies are the owner's alone).
2. **Inside a private item** (`inside_private`): intro line `Back up the private item itself, from its own shield.`; no create controls.
3. **The owner's own private item** (`private && mine`):
   - Keep the drive and cloud sections and their controls.
   - Replace the second intro line with: `Only you can back this up. Its cloud copy opens only with your recovery phrase.`
   - Keep `Private items inside aren't included. Their owners back them up separately.` as a third line (nested private items are their own backups).
   - Cloud row with `old_phrase_copies` not null: a line `Older versions sealed with your old phrase · removed <date>` (date with the same date helper the sheet already uses for `last_ok_at`; find it with `grep -n "format\|toLocale" components/files/ProtectSheet.jsx | head`), plus an `InfoHint` "These were made before you got a new recovery phrase. They open only with the old phrase." and a `Button variant="accent"` `Remove now` (surface named for its real backdrop, see AGENTS.md). Remove now opens `ConfirmModal` title `Remove older cloud versions?`, body `Earlier versions and deleted files that only exist in these older versions will be gone.`, confirm label `Remove`. On confirm: `DELETE /api/v1/private-backups/old-copies`, then `addToast({ type: "success", message: "Older versions will be removed" })` and invalidate `["cloud-backups"]`. A failure shows in the sheet's existing error `PageNotice` as `Could not remove the older versions. Try again.` (the modal is closed by then, so a toast is also fine; pick the one the sheet already uses for other delete failures and say which in the report).
4. **Shared folders**: unchanged.

Copy rules: sentence case, `InlinePill` for the owner name, no "scope/pack/snapshot". Toasts only for the user action above. No new haptics (Button/ConfirmModal own them).
