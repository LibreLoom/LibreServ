```rust
/// The owner's active scope, made if missing. A scope whose x25519_public differs from the owner's
/// current key (they got a new phrase) is retired here: state "old_phrase", retire_after = now + OLD_PHRASE_GRACE.
/// Returns (scope, true) when a new scope was made.
pub fn ensure_scope(conn: &Connection, owner: &str, owner_public: &[u8; 32], now: i64) -> Result<(db::PrivateScope, bool)>;
/// Put pscopes/<scope> on Connect (idempotent; called on every private run).
pub fn publish_scope(store: &dyn CloudStore, signer: &Signer, luna_id: &str, scope: &db::PrivateScope, auth_public: &[u8; 32]) -> Result<()>;
/// The signed private open message (for tests, fixture, and to document the format).
pub fn open_message(luna_id: &str, scope: &str, challenge: &[u8; 32]) -> Vec<u8>;
```
Details:
- `ensure_scope`: `active_private_scope(owner)`; if it exists and its `x25519_public == owner_public` → return it. If it exists with another key → `set_private_scope_state(old, "old_phrase", now + OLD_PHRASE_GRACE)`. A `recovered` scope is never returned as active (it is a different state already). Then make a new one: `dedup = random 32` (use `getrandom::getrandom`), scope from `scope_of`, insert with `state "active"`.
- `publish_scope`: build `ScopeRecord` (`user_id = scope.owner`, `created_at = scope.created_at`, `sealed_dedup = seal_dedup(...)`), sign, `store.put_record(PSCOPES_KIND, &scope.scope, &bytes)`. Map `StoreError` with `anyhow!("{e}")` like `run.rs`.
- `open_message` = `crypto::canonical(&[("luna_id", …), ("scope", …), ("challenge", challenge)])`.
- `signed_bytes` field names and order exactly: `luna_id, scope, user_id, x25519_public, auth_public, created_at (i64 BE), sealed_dedup`.

## Tests (in private.rs)
- `seal_and_open_round_trip` for pack key, tree, meta and dedup using `crypto::derive(&[0u8;16], "luna-x")` keys.
- `wrong_scope_fails_to_open`: sealed for scope A, opened with scope B → Err.
- `scope_record_signs_and_verifies`; flipping one byte of `sealed_dedup` fails verify.
- `ensure_scope_reuses_then_retires_on_new_key`: same key twice → same scope, `is_new` false the 2nd time; new key → old scope `old_phrase` with `retire_after == now + OLD_PHRASE_GRACE`, new scope active.
- `snapshot_record_ref_picks_the_kind`: private snapshot (via `db::commit_private_snapshot_tx`) → `("psnapshots", "<scope>.<id>")`; shared → `("snapshots", id)`.
- `publish_scope_writes_one_record` with `MemoryStore` (`store.rs`), then `SignedScope::from_bytes(...).verify(&signer.public())` holds.
- format.rs: a test that a record signed with `sign_with(PRIVATE_SNAPSHOT_DOMAIN)` fails plain `verify()` and passes `verify_with(.., PRIVATE_SNAPSHOT_DOMAIN)`.
