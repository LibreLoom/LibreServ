## lib/privateRestore.js
```js
export const PRIVATE_RESTORE_QUERY_KEY = ["cloud-restore-private"];
export const PRIVATE_RESTORE_PATH = "/api/v1/cloud/restore-private";
/** @returns {Promise<{ needed: boolean, luna_id: string, signing_public: string, scopes: number }>} */
export function getPrivateRestoreStatus();
/** @returns {Promise<{ restored: number }>} total over all scopes */
export async function restorePrivateFromPhrase(words, { lunaId, signingPublic });
```
Steps in `restorePrivateFromPhrase`:
1. `entropy = phraseToEntropy(words)` (throws a plain sentence for bad words).
2. Fetch `pscopes` and `psnapshots` from `${PATH}/records/{kind}` (same decode as `cloudRestore.js fetchRecords`).
3. `findMyPrivateScopes({ lunaId, entropy, pscopes, signingPublics: [fromBase64(signingPublic)] })`. None → throw `Error("This recovery phrase doesn't open any private backups on this Luna. Check each word.")`.
4. Per scope: `readPrivateSnapshots(...)`; per snapshot fetch `${PATH}/packs/${treePackId}` as bytes (`fetch` with `credentials: "include"`, check `res.ok`, else throw `"Could not download part of your private backups. Check your connection, then try again."`), then `readRawTreeWith(bytes, snap, privateUnwrap(x25519Secret, lunaId, scope), openPrivateTreeBytes(x25519Secret, lunaId, scope))`. `x25519Secret` from `derive(entropy, lunaId)`.
5. `postJson(PATH, { scope, dedup_key: toBase64(dedupKey), snapshots: [{ snapshot_id, protection_id, record: toBase64(recordBytes), meta: { name, source_drive, source_path }, tree }] })`. Sum `restored`.
