# P5-T7: end-to-end cross-check, web fetches against backend routes and JSON fields (wave 3)

Read first: `brief-common.md`, `p4-plan.md` (shared contracts), `p5-plan.md` (contracts). **Read-only task: edit no files.** Your output is the report.

## Scope (the files phases 4 and 5 touched)
- Luna web: `luna/web/src/components/dashboard/{BackupsCard,AllBackupsModal}.jsx`, `lib/backupRows.js`, `components/files/{ProtectSheet,DriveFileExplorer,FileRow}.jsx`, `components/settings/categories/CloudBackupCategory.jsx`, `components/cloud/PrivateRestoreCard.jsx`, `lib/privateRestore.js`, `lib/cloudPhrase.js`.
- Shared JS: `luna/web/src/lib/cloudFormat.js`, `cloudPrivate.js` (find their real paths with `grep -rln "openPackWith\|cloudPrivate" luna --include=*.js | grep -v node_modules`).
- Connect web: `luna/connect/web/src/**` files that call `privateUnlock`, `cloudSource` private methods, `CloudBrowser`, `PrivateItemsRow`.
- Backends: lunad routes (`grep -rn "\.route(" luna/crates/lunad/src/api`), Connect routes (`grep -rn "r\.\(Get\|Post\|Put\|Delete\|Route\)\|\.Handle" luna/connect/internal/api`).

## Steps
1. List every request in the web scope: `grep -rn "getJson\|postJson\|putJson\|deleteJson\|fetch(\|apiFetch\|request(" <files>`. For each: method, URL (with params), file:line.
2. Find the matching backend route and handler (file:line). Mark `MISSING` if none, `METHOD` if the method differs.
3. For each request, list the JSON fields the web reads (`data.x`, `row.x`, destructuring) and the fields it sends; check each against the handler's `json!({...})` / serde struct / Go struct tags. Mark `FIELD?` for any name the handler doesn't produce or accept (watch snake_case vs camelCase, `private` vs `is_private`, `check_due`, `old_phrase_copies`, `can_delete`, `needs_look`, `owners`, `X-Private-Token`).
4. Query keys: list every `queryKey` and every `invalidateQueries` in scope; flag an invalidation whose key no query uses (typos like `cloudBackups` vs `cloud-backups`).
5. Toast audit: `grep -n "addToast\|toast(" ` in the dashboard and files scope. Each must follow a user action (button, confirm); flag any inside a query, effect or poll.
6. Copy audit for the touched UI: `grep -n -i "backup\b\|\bbacked\|private" ` in the dashboard files, `system/system_health.rs` messages: flag any private item's name or path that could reach someone other than its owner.

## Report (under 600 words)
A table: `Method | URL | Web file:line | Handler file:line | Fields read/sent | Status (OK / MISSING / METHOD / FIELD?)`, then lists for query keys, toasts and copy. End with "Fixes needed" naming file, line and the one-line change; the orchestrator assigns them.
