## private_recover.rs
```rust
pub struct PrivateSnapshotIn { pub snapshot_id: String, pub protection_id: String, pub record: Vec<u8>, pub meta: PlainMeta, pub tree: Tree }
pub struct PlainMeta { pub name: String, pub source_drive: String, pub source_path: String }
/// Records the caller may see: pscopes whose x25519_public is `caller_public`, and psnapshots under those scopes.
pub fn caller_scopes(store: &dyn CloudStore, luna_public: &[u8; 32], caller_public: &[u8; 32]) -> Result<Vec<ScopeRecord>>;
/// Tree pack ids named in the caller's psnapshots (the only packs the browser may fetch through Luna).
pub fn caller_tree_packs(store: &dyn CloudStore, luna_public: &[u8; 32], scopes: &[ScopeRecord]) -> Result<HashSet<String>>;
/// Check and write the plain index. Returns how many snapshots were added.
pub fn write_private_index(conn: &mut Connection, luna_public: &[u8; 32], caller: &str, caller_public: &[u8; 32],
    scope: &ScopeRecord, dedup_key: &[u8; 32], snapshots: Vec<PrivateSnapshotIn>, now: i64) -> Result<usize>;
```
`write_private_index` rules (all in one transaction; any failure writes nothing):
1. `private::scope_of(dedup_key).1 == scope.scope`, else `"These private backups don't match the key your browser sent. Start again."`.
2. `scope.x25519_public == caller_public`, else `"These private backups belong to another recovery phrase."`.
3. Each snapshot: `SignedRecord::from_bytes(record)?.verify_with(luna_public, PRIVATE_SNAPSHOT_DOMAIN)`; `record.snapshot_id == snapshot_id`, `record.protection_id == protection_id`, `record.key_version == 0`. Skip (don't fail) a snapshot already in `cloud_snapshots`.
4. Scope row: `insert_private_scope` with `state "recovered"`, owner = caller, `retire_after 0`, `created_at = scope.created_at` (skip if it exists).
5. Protection per distinct `protection_id` that does not exist: kind cloud, `private_owner = caller`, `created_by = caller`, source from meta (normalize the path). State: `active` if `access_list::private_source(conn, drive, path)` is `OwnItem{owner}` with `owner == caller`, else `stopped` with `"This folder is no longer a private item."`. Access list `{"users":[caller],"admins":false}`.
6. Snapshot rows: `commit_private_snapshot_tx` equivalent inside the same transaction (if T1's helper opens its own transaction, insert in sequence through it per snapshot instead and say so in the report). Pack ids = tree pack + every `chunk.pack` in the tree. Chunks: `insert_chunk(scope, id, pack, offset, len)` for every tree chunk and the tree chunk itself (`tree_hash`, offset/len unknown → look at how `recover.rs` ~235 handles the tree chunk and do the same). Packs: insert as `live` the way `recover.rs` does (`grep -n "insert_pending_pack\|live" recover.rs db.rs | head`). Tree JSON = `serde_json::to_vec(&tree)`.

## api/cloud_restore_private.rs routes (signed-in user; caller must have `user_keys`, else 400 `"Set up your recovery phrase on this Luna first."`)
- `GET /api/v1/cloud/restore-private` → `{"needed","luna_id","signing_public","scopes"}` per the plan (`signing_public` base64 like `cloud_restore.rs` status; `scopes` = how many of the caller's scopes Luna lacks). Connect missing or unreachable, or no phrase → `needed:false` with 200 (never an error: the web card just hides).
- `GET /api/v1/cloud/restore-private/records/{kind}`, kinds `pscopes` | `psnapshots` (else 400), same JSON shape as `records_with_store`, filtered by `caller_scopes`.
- `GET /api/v1/cloud/restore-private/packs/{id}`: 64 hex; must be in `caller_tree_packs`, else 404 `"Luna can't find that backup file."`; returns `application/octet-stream`.
- `POST /api/v1/cloud/restore-private` body per plan (base64 for `dedup_key` and `record`). Loads the `pscopes/<scope>` record from the store itself (never trusts the browser for it) and verifies it with the Luna identity public; then `write_private_index`. → `{"restored": n}`.
- Connect not set up → same "not set up" error as `cloud_restore.rs`; unreachable → its 503.
- Blocking work in `spawn_blocking`, no DB lock held during store calls.
