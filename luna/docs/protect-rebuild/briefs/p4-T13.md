## cloudFormat.js
- `verifySnapshot(bytes, signingPublics, lunaId, domain = 'snapshot')`: pass `domain` to `verify`.
- `openPackWith(bytes, idHex, unwrapKey)`: `unwrapKey(wrapped: Uint8Array) => Uint8Array(32)`. `openPack(bytes, idHex, backupKey)` becomes `openPackWith(bytes, idHex, (w) => decrypt(backupKey, PACK_KEY_WRAP_AAD, w))`. Same errors (`CHANGED`, `DAMAGED`).
- `readTreeWith(treePackBytes, snap, unwrapKey, openTreeBytes)`: `openTreeBytes(sealed) => Uint8Array json`. `readTree` delegates.
- `makePackReaderWith(getPack, unwrapKey, keep = 3)`; `makePackReader` delegates.
- `readRawTreeWith(treePackBytes, snap, unwrapKey, openTreeBytes)`: same checks as `readTreeWith` but returns the decrypted tree JSON object exactly as Luna wrote it (`{entries:[{path,size,mtime,chunks:[{id,pack,offset,len}]}]}`, hex strings untouched). T16 sends it back to Luna when rebuilding a private index.

/** @returns {{lunaId, scope, userId, x25519Public, authPublic, createdAt, sealedDedup} | null} never throws */
export function verifyScopeRecord(bytes, signingPublics, lunaId)

/** The scopes this phrase owns: verified scope records whose x25519Public equals the phrase's key, with the dedup key opened.
 * @returns {Array<{scope, userId, createdAt, dedupKey}>} newest first */
export function findMyPrivateScopes({ lunaId, entropy, pscopes, signingPublics })
/** Private snapshots of one scope, verified and with meta opened. psnapshots names are "<scope>.<snapshot_id>". */
export function readPrivateSnapshots({ lunaId, entropy, scope, psnapshots, signingPublics })

Byte rules (must match Rust exactly):
- Purposes: `luna-private-pack-key-v1`, `luna-private-tree-v1`, `luna-private-meta-v1`, `luna-private-dedup-v1`.
- Scope record signed message: canonical `luna_id, scope, user_id, x25519_public (32), auth_public (32), created_at (i64 BE 8), sealed_dedup`; JSON fields are hex.
- Use `BigInt` for `created_at` as `snapshotSignedBytes` does.

## cloudKeys.js
- `findMyKeys({..., pscopes = []})`: add the `user_id` of every `pscopes` record (parse JSON, no trust needed yet) to the candidate ids used to find the signing key via `self/<part>`. Return also `privateScopes: findMyPrivateScopes(...)`. Throw `NO_BACKUPS` only when both `keys` and `privateScopes` are empty. A person with only private items gets `keys: []` and their scopes.
