## Behaviour
1. `CloudBrowser` gets a new prop `privateOwners` (default `[]`) and calls `groupByStarter(backups, privateOwners)`.
2. Inside each group, render shared backups as today (exclude `backup.private` ones from the plain rows), then one `PrivateItemsRow` at the end when `group.privateRow` is set.
3. `PrivateItemsRow` props `{ kind: "mine" | "other", backups, onOpen }`:
   - Title `Private items`, plus an `InfoHint`-style hint if Connect web has one (else a short second line): `Only this person's recovery phrase opens these.`
   - `kind "other"`: that line only. No counts, sizes, names or status.
   - `kind "mine"`: the line `Opened with your recovery phrase.` and the private backups listed inside the row, one line each with name + `N versions · Latest <when>` and an `Open` button (same as shared rows, calling `openBackup(protectionId)`), so the existing version picker, file list and downloads work unchanged (T17 made `loadTree`/downloads private-aware).
4. Group names: unchanged rules; a group with only private items of someone else reads `Another person on this Luna` (T17 sets it).
5. Pages: `BackupsPage` and `SharePage` read `privateOwners` from `unlockBackups(...)` and pass it to `CloudBrowser`. Nothing else changes there.
6. No toasts (nothing here is a mutation).
