## Rules
1. **Kinds.** `browserKinds` gains `pscopes` and `psnapshots`.
2. **Which scopes are private:** a pack scope is private when a `pscopes/<scope>` record exists for that account + Luna. Add `privateScopes(d Deps, s readScope) (map[string]bool, error)` (record names of kind `pscopes`; use `recordNames`).
3. **`pscopes` reads:** account: all. Share link: `Kind "user"` → only records whose parsed `user_id` has `scopePart(user_id) == s.Value` (use T5's `parseScopeRecord`; drop records that fail verification); `Kind "backup"` → none.
4. **`psnapshots` reads** need `X-Private-Token`; `privateSessionScope(d, s, linkID, token, now)` gives the scope; return only names with prefix `<scope>.`. No or bad token → 403 `privateTokenMessage`.
5. **Packs.** In `writePack` (or `packAllowed`), before serving: look up the pack's `storage_packs.scope`; if it is private, require a token whose scope equals it, else 403 `privateTokenMessage`. This applies to `Kind ""` (account) too: today `packAllowed` returns true early for Kind ""; the private check must run before that early return. Shared packs keep today's rules.
6. **Share filters for shared kinds** stay as they are; a private scope never appears in `allowedPackScopes` for a backup link.
7. **Routes (server.go):**
   - account group (next to `/cloud/lunas/{lunaID}/packs/{id}`): `POST /cloud/lunas/{lunaID}/private/challenge` → `priv.Challenge`, `POST /cloud/lunas/{lunaID}/private/open` → `priv.Open`, with `priv := handlers.PrivateHandler{Deps: s.deps}` built where `cloud`/`share` are built.
   - public share routes (next to `/share/packs/{id}`): `POST /share/private/challenge` → `priv.ShareChallenge`, `POST /share/private/open` → `priv.ShareOpen`.
   - CORS: if the server has an allowed-headers list (`grep -n "Allow-Headers\|AllowedHeaders" -r internal/api | head`), add `X-Private-Token`.
