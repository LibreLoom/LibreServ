## ops.rs
1. **`check_new_backup`** (~126): replace the `inside_private` refusal with `access_list::private_source`:
   - `Shared` → as today.
   - `OwnItem{owner}` and `owner == user.id` → allowed; it is a private backup.
   - `OwnItem{owner}` else → `"Only <name> can back up this item."` (display name, else username, else "its owner").
   - `Inside` → `"Back up the private item itself, from its own shield."`
   Return the owner too: change it to `-> Result<(Option<ProtectionRow>, String), Refused>` and update `create`.
   The phrase rule stays: the creator needs a phrase ("Set up your recovery phrase before you back up to the cloud.").
2. **`create`**: insert with `private_owner: &owner`; access list from `access_list::for_row` on the new row (or build `AccessList{users: vec![owner], admins: false}` directly when `owner` is set, same result).
3. **`run`**: read the row; if `private_owner` is set call `private_run::run_once(db, id, store, accept_missing, now)` instead of `run::run_once`. Everything around it (publish_users, tidy, card marker, record) stays.
4. **`tidy` / `sweep`**: unchanged calls; retention handles private kinds (below). Add to `sweep`, before the thin loop, `retire_old_phrase_scopes(db, store, now)`:
   - For each `db::list_private_scopes(None)` with `state == "old_phrase"`, `retire_after > 0` and `now >= retire_after`:
     a. for each id in `db::private_snapshot_ids(scope)`: delete `psnapshots/<scope>.<id>` on the store (`NotFound` is fine), then `db::delete_cloud_snapshot`.
     b. `retention::thin(db, "", scope, store, now)` marks its packs.
     c. When no pack of that scope is left in any state (`db::list_packs(conn, scope, state)` for `live`, `marked`, `deleting`, `pending` all empty): delete `pscopes/<scope>` on the store and `db::delete_private_scope`. Until then keep both, so Connect still knows the packs are private.
   - Store errors: log and stop this pass (next sweep retries).
5. **`delete`**: delete each snapshot record with `private::snapshot_record_ref(conn, id)` instead of the literal `"snapshots"`. Keep the keys/recipients prefix cleanup (it finds nothing for a private row). Never delete the `pscopes` record here: other private items of the same owner share the scope.
6. **`record`**: already calls `for_row` (T1). Nothing else.
7. **`check`**: if the row is private, call `private_check::check(db, id, store, sample, now)` instead of `check::check`; the rest (recording the check) is shared.
8. **`on_grants_changed`** (~481): skip rows with `private_owner` set (their list never follows grants for cloud).
9. Add for T11:
   ```rust
   /// The owner's retired-scope versions still waiting: (count, earliest removal time). None if there are none.
   pub fn old_phrase_copies(conn: &Connection, owner: &str) -> Option<(usize, i64)>;
   /// Remove the owner's old-phrase versions on the next sweep.
   pub fn retire_old_phrase_now(conn: &Connection, owner: &str, now: i64) -> anyhow::Result<()>; // retire_after = now for each old_phrase scope
   ```

## retention.rs (`thin`)
- Skip snapshots whose scope is a private scope in state `old_phrase` (they wait for the 30 days, then the sweep removes them whole). Use `db::private_scope_of_snapshot` + `db::get_private_scope`.
- Delete a snapshot's record with `crate::backup::cloud::private::snapshot_record_ref(&conn, &snap.id)` instead of `"snapshots"`.
- The "index 0 is always kept" rule applies to the snapshots that remain after the skip.
