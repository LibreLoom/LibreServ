## cloudSource.js
Add to both `accountSource(lunaId)` and `shareSource(token, lunaId)`:
```js
privateChallenge: () => Promise<string>,                       // hex; POST …/private/challenge
privateOpen: ({ scope, challenge, signature }) => Promise<{ token: string, expiresAt: number }>, // POST …/private/open, hex fields
withPrivateToken: (token) => CloudSource,                      // same source, adds header X-Private-Token
```
Account: `POST /api/v1/cloud/lunas/{lunaId}/private/challenge` and `/private/open`. Share: `POST /api/v1/share/private/challenge` and `/api/v1/share/private/open` with `X-Share-Token`. Use `credentials: "include"` and the file's `failed()` helper; fallback sentence `"Could not open your private items. Check your connection, then try again."`. A 403 keeps the server's sentence.

## privateUnlock.js
```js
/** @typedef {{ scope: string, x25519Secret: Uint8Array, dedupKey: Uint8Array, source: CloudSource }} PrivateKeys */
/** Open one scope: challenge → signPrivateOpen(authSecret) → open → token source → psnapshots → versions.
 * @returns {Promise<CloudBackup[]>} one CloudBackup per protection, with `private: PrivateKeys` set and `keys: {}` */
export async function openPrivateScope(source, entropy, lunaId, scopeInfo, signingPublics);
/** Every scope this phrase owns, opened. Old-phrase scopes are just more scopes. */
export async function unlockPrivate(source, entropy, lunaId, privateScopes, signingPublics);
```
- `CloudBackup` for private: `{ protectionId, name, sourcePath, startedBy, startedByName, versions, keys: {}, private: PrivateKeys }`, with meta from `openPrivateMeta`; versions sorted newest first. Same `CloudVersion` shape (keyVersion 0).
- Copy rules for thrown errors: `"Could not open your private items. Try again."` when a session can't be opened for another reason than 403.

## cloudUnlock.js
- `unlockBackups(source, words, opts)`: also list `pscopes`; pass it to `findMyKeys`; after the shared part, `unlockPrivate(...)` for `mine.privateScopes`, and append those backups. Return `{ userIds, backups, privateOwners }` where `privateOwners` = user ids of every verified `pscopes` record (any owner, verified with `mine.signingPublics`; `verifyScopeRecord`), deduped. Throw `NO_BACKUPS` only when `backups` is empty AND `privateOwners` is empty.
- `requireLatest` keeps filtering shared backups only.
- `groupByStarter(backups, privateOwners = [])`: each group gets `privateRow: "mine" | "other" | null`: `"mine"` when the group contains a backup with `private`, `"other"` when `startedBy` is in `privateOwners` without an opened private backup, else null. A `privateOwners` id with no group gets its own group `{ startedBy, name: "Another person on this Luna", backups: [], privateRow: "other" }`. Private backups stay in `group.backups` (the UI decides how to show them).
- `loadTree(source, backup, version)`: if `backup.private`, fetch from `backup.private.source` and use `readTreeWith(pack, version, privateUnwrap(...), openPrivateTreeBytes(...))`; else as today.
