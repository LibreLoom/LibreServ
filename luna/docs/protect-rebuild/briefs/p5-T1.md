1. In both the drive loop and the cloud loop, `continue` for rows with `!row.private_owner.is_empty()`. Also skip private rows in the "people on the list without a phrase" part of the cloud loop.
2. After the loops, one check per private owner (`private_backups_{owner_id}`, category `"backups"`):
   - `owner_name` = display name, else username; a deleted owner (`private::owner_state != Active`) → "a deleted user" (capitalize the first letter when it starts a sentence: "A deleted user's private items are backed up.").
   - Count rows needing a look with the same rules the loops use (stopped/source_gone → not a problem; drive `state != Ok`; cloud `Failing`, 2-day stale, or `last_check_problem`).
   - None: PASSED, `"{owner_name}'s private items are backed up."`

   - `details`: `{ "backups": total, "needs_look": n }` only. Never a path, folder or drive name.
